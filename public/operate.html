LIVE WORKSPACE SETUP

이제 실제 업무용 서버로

데모와 운영은 분리되어 있습니다. 실제 데이터는 인증된 운영 서버에서만 관리합니다.

현재 상태

운영 서버 코드 구현·로컬 테스트 완료. Render 배포와 Gmail OAuth 계정 설정은 아직 필요합니다. 이 GitHub Pages 주소에서는 서버나 실제 발송 기능을 실행할 수 없습니다.

운영 버전에는 관리자 로그인, 서버 DB 저장, 실제 후보·상품·템플릿 관리, Gmail 공식 연결·승인 발송·답장 동기화, Instagram 공식 수신·제한된 회신, 수동 DM 기록이 있습니다. 계정·권한 연결 전에는 외부 API 작업이 되지 않습니다.

운영 시작 순서

  1. Render 계정으로 저장소를 연결하고 배포 구성을 확인합니다. 현재 구성은 유료 Starter 서버와 영구 디스크를 사용하도록 준비되어 있습니다. 가격 확인·별도 승인 전에는 생성하거나 결제하지 마세요.
  2. Render 외부 주소는 자동 인식됩니다. Google Cloud OAuth 클라이언트 ID·시크릿을 Render의 비공개 환경 변수에 입력합니다. 비밀번호나 시크릿을 채팅으로 보내지 마세요.
  3. 운영 서버의 /app/에 접속해 SANJI_SETUP_TOKEN으로 첫 관리자 계정을 만듭니다. 이 토큰은 Render 환경 설정에서 확인합니다.
  4. 연동 설정에서 본인 Gmail을 공식 로그인으로 연결합니다. 테스트 수신자와 최종 카피를 확인한 후에만 실제 발송 활성화를 별도로 진행합니다.

아직 운영 URL이 발급되지 않았습니다. 기존 데모에서 실제 발송이 되는 것처럼 표시하지 않습니다. 신규 상대에게 Instagram 자동 DM을 보내는 기능은 공식 API 제한상 제공하지 않습니다.
