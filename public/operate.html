운영 워크스페이스

공개 키와 인증 서비스 연결을 확인했습니다. 관리자 계정·DB 구조·멤버십은 프로젝트 관리자 설정이 필요합니다. 외부 메일·DM은 기본 비활성입니다.
운영 로그인 열기 →설정 안내 ↗

처음 한 번 설정

  1. Supabase Authentication → Users에서 관리자 계정을 만듭니다.
  2. SQL Editor에서 준비된 DB 생성 SQL과 관리자 등록 SQL을 실행합니다.
  3. 메일·검색·DM까지 연결하려면 준비된 workspace Edge Function을 배포하고 공식 OAuth 앱을 설정합니다.

DB는 사용자별 접근 정책으로 보호되며, 외부 토큰은 서버에서 암호화합니다. 공개 키만으로 DB 구조 생성·함수 배포를 대신할 수는 없습니다.
