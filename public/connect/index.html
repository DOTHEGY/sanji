공개 키로 서버 함수를 배포할 수는 없습니다. 아래 과정을 프로젝트 관리자가 한 번 적용해야 합니다. 비밀 키나 계정 비밀번호를 이 페이지에 입력하지 마세요.

1. workspace 함수 배포

  1. Supabase Edge Functions 열기 → Deploy a new function → Via Editor.
  2. 함수 이름을 workspace로 지정합니다. 아래 전체 코드 복사 후 기본 코드를 모두 지우고 붙여넣습니다.
  3. Deploy function을 누릅니다. 이미 workspace가 있다면 기존 코드를 이 버전으로 교체합니다.
  4. 함수 설정의 Verify JWT / legacy JWT verification을 끕니다. 함수 내부에서 로그인 토큰과 관리자 권한을 직접 검증합니다.

2. 비공개 Secrets 설정

Edge Function Secrets에서 입력합니다. 이 값들은 채팅·GitHub·일반 앱 입력창에 넣지 않습니다.

  • TOKEN_ENCRYPTION_KEY: 32바이트 이상의 강한 임의 문자열. OAuth 토큰 암호화용.
  • GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET: Google OAuth 앱 설정. 아래 콜백 URI를 등록합니다.
    https://ofasbfpeapbdcotnptvz.supabase.co/functions/v1/workspace/oauth/gmail/callback
  • AI_API_KEY: OpenAI API 키. AI 도입부 생성 버튼을 눌렀을 때만 사용합니다. API 사용료와 한도를 먼저 확인하세요. 기본 모델은 gpt-4.1-mini이며 AI_MODEL로 변경 가능합니다.
  • EMAIL_SENDING_ENABLED: 처음에는 false. Gmail 연결과 본인 테스트 수신자 확인·별도 발송 승인 후에만 true.
  • JOB_RUNNER_TOKEN: 32자 이상의 별도 임의 문자열. Cron 작업 인증용.

APP_ORIGIN 기본값은 https://dothegy.github.io, APP_FRONTEND_URL은 https://dothegy.github.io/sanji/workspace/ 입니다. Supabase 서버용 기본 키는 런타임에서 사용하며 브라우저에 넣지 않습니다.

3. 예약 자동 발송 설치

기존 DB 설치를 마쳤다면 아래 추가 SQL만 Supabase SQL Editor에서 실행하세요. 승인한 미리보기만 예약 큐에 넣으며, 발송 직전 수신 거부·버전·일일 제한을 다시 검사합니다.

SQL 다운로드SQL Editor 열기

Supabase Cron에서 1분마다 실행하는 HTTP 요청을 등록하세요.

  • 스케줄: * * * * *
  • 메서드: POST
  • URL: https://ofasbfpeapbdcotnptvz.supabase.co/functions/v1/workspace/jobs/run
  • 헤더: Content-Type: application/json, x-job-token: Secrets에 설정한 JOB_RUNNER_TOKEN 값
  • 본문: {}

Cron은 호출당 최대 1건을 처리합니다. 실패·결과 불확실 건은 자동 재시도하지 않습니다. 브라우저를 닫아도 Cron이 설정되어 있으면 실행됩니다. 예약 토큰만 설정하고 Cron을 만들지 않으면 자동 발송되지 않습니다. Instagram 신규 DM 예약은 지원하지 않습니다.

4. 카피 넣는 곳

운영 화면 → 템플릿 → 템플릿 추가 → 공통 본문 카피에 작성하고 저장합니다. 템플릿의 사용 버튼 → 수신자 선택 → AI 도입부 1~2줄 생성을 누르면 공개 콘텐츠 근거로 도입부만 제안합니다.

앞의 도입부와 공통 본문은 별도 칸입니다. AI가 공통 본문·가격·일정·서명을 바꾸지 않습니다. 최종 미리보기 승인 후 즉시 발송하거나 승인한 내용 예약 자동 발송을 선택하세요.
