4. 관리자 접근 권한 등록

먼저 Supabase Authentication → Users에서 관리자 계정을 생성하세요. 아래에 그 계정의 이메일을 입력합니다. 이메일은 이 브라우저에서 SQL을 만드는 용도로만 사용하며 서버에 전송하거나 저장하지 않습니다.

실행 결과에 관리자 계정이 한 줄 표시돼야 합니다. 빈 결과라면 Authentication 계정 생성 여부와 이메일을 확인하세요.

이 페이지는 SQL을 대신 실행하지 않습니다. 공개 키에는 DB 생성 권한이 없으므로 프로젝트 관리자 화면에서 실행해야 합니다. 기존 업무 자료를 지우거나 실제 메시지를 발송하지 않습니다.
