# 산지 PC 실행기 (내부용)

Node.js 22 이상 설치 후 이 폴더에서 터미널을 엽니다. Windows PowerShell/macOS 터미널 모두 같습니다.

```sh
npm install
npx playwright install chromium
npm start
```

1. 산지 → 크리에이터 목록에서 발신 Instagram 아이디와 DM 카피를 저장합니다.
2. **PC 연결 키 발급**을 누르고 표시된 키를 PC 터미널에 입력합니다. 키는 7일 유효하며 재발급/해제하면 이전 키는 무효입니다. 키를 채팅이나 타인에게 보내지 마세요.
3. 실행기가 연 브라우저에서 직접 Instagram에 로그인하고 2단계 인증을 완료합니다. 비밀번호는 산지에 입력하지 않습니다. DB 세션 백업이 켜져 있으면 Instagram 쿠키·저장소 상태만 HTTPS로 보내 서버에서 암호화해 7일간 보관하고 다음 실행 때 복원합니다. 다른 사이트의 세션은 백업하지 않습니다. 복원 후에도 본인 계정을 확인하며 만료·2단계 인증은 직접 처리해야 합니다.
4. 기본 `npm start`는 공개 프로필 상단 이미지·화면에 표시된 소개와 수치를 수집합니다. 비공개 계정·접근 제한·알 수 없는 수치는 채우지 않습니다. 한 번 실행할 때 최대 5개, 하루 최대 50개 프로필을 확인합니다. 이미지는 비공개 저장소에 저장됩니다.
5. DM을 보내려면 웹에서 대상·최종 카피를 펼쳐 확인하고 **선택한 DM 승인·PC 대기열에 넣기**를 누릅니다. 실제 실행은 `npm run send` 후 터미널에서 `SEND`를 입력하고 수신자·본문을 확인한 뒤 해당 아이디를 한 번 더 입력해야 합니다. 매 실행에서 DM은 1건만 처리하고 종료합니다. 이 과정부터 승인 대상에게 실제 DM이 전송될 수 있습니다.

PC가 켜져 있고 실행기가 동작해야 처리됩니다. 종료는 Ctrl+C. 웹의 **PC 연결 해제**로 다음 작업·전송 직전 검증을 중단할 수 있으나 이미 클릭된 전송을 취소할 수는 없습니다. 웹에서 승인하지 않은 대상·수정된 카피는 보내지 않습니다. 검색 자동화와 발송 승인은 별도입니다.

프로필은 공식 Instagram 웹 화면에서 확인하며 API의 선제 DM 지원을 의미하지 않습니다. 자동 팔로우·보안문자 우회·계정 제한 우회·계정 순환은 없습니다. 제한·인증·계정 불일치·수신자 불확실성에서 멈춥니다. 플랫폼 정책상 허용을 보장하는 방식이 아닙니다.

`전송 화면 확인`은 실제 전달/열람 확인이 아닙니다. 클릭 이후 상태가 불확실하거나 실행기가 종료되면 결과 미확인으로 남기고 자동 재시도하지 않습니다. 프로필 정보는 화면 확인 시점 정보이며 최신 여부를 보장하지 않습니다. Instagram 화면이 바뀌면 전송 전 안전하게 실패할 수 있습니다.

로그인 프로필·실행 중 전송 기록은 PC의 `~/.sanji-instagram/`에 저장됩니다. 공유 PC에서는 사용하지 말고 다른 사람에게 폴더를 전달하지 마세요. 연결 키는 파일에 저장하지 않습니다. DB 백업을 끄거나 저장된 세션을 삭제하려면 웹의 「DB 로그인 세션 삭제·백업 끄기」를 누르세요. 기존 PC 키가 해제되므로 계속 사용하려면 새 키를 발급합니다. DB에서 삭제해도 PC의 브라우저 프로필은 직접 삭제하거나 로그아웃해야 합니다. 초기 설치는 무료 패키지·브라우저를 내려받으며 서버 추가 구매는 필요 없습니다. 기존 Supabase 저장/네트워크 요금제 사용량은 발생할 수 있습니다.
