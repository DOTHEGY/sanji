# 상품 검색과 발송 메일 필터

상품명 미확인 초안은 브랜드 기준으로 먼저 저장하되 상품 조사는 별도 예약기에서 계속한다. 공식 페이지에 특정 상품명이 없으면 네이버/Google 공개 검색을 통해 쿠팡, 올리브영, 네이버 스마트스토어·브랜드스토어의 상품 상세 링크를 찾는다. 브랜드명이 일치하는 식품 상품 제목만 후보로 사용한다. robots·HTTP 차단은 우회하지 않는다. 외부 판매처에서 이메일을 수집하거나 기존 브랜드 이메일을 교체하지 않는다.

상품 원문에서 확인한 이름과 검색 색인에서 확인한 이름을 구분한다. 검색 색인만 확인한 경우 판매 원문·현재 판매 여부·판매자 권한·공급 조건을 확인했다고 주장하지 않는다. 이런 조건은 여전히 미확인이다. 실제 공개 검색 시험에서 드시모네 키즈 요거트 플레인, 1킬로커피 에티오피아 예가체프 드립백 커피의 쿠팡 링크를 찾았다. 쿠팡 원문은 robots 제한으로 수집하지 않았다. 이미 발송한 업체이므로 이 시험으로 발송 원문이나 예약을 변경하지 않았다.

`sanji-product-research` 예약기는 2분 간격으로 미발송 상품 미확인 초안을 하나씩 조사한다. 메일을 보내거나 예약을 생성하지 않는다. 같은 업체 외부 검색은 최대 3회, 15분 간격으로 제한한다. 새 초안/상품으로 바뀌면 상품 대기열에서 제외한다. 기존 발송 목표·발송량·추적 설정을 변경하지 않는다. 신규 유료 검색/AI API는 사용하지 않지만 Supabase 기존 함수·DB·네트워크 사용량은 발생한다.

브랜드 이메일 화면에 `열람 추정만`, `회신 확인만` 탭을 추가했다. 열람 추정은 승인된 추적 서비스 보고서가 연결된 경우에만 실제 기록을 표시한다. 자동 요청 의심, 내부 시험, 복수 수신자 공유 추적을 제외한다. 현재 운영 영업 메일의 픽셀 추적 서비스는 미배포/비활성화 상태이므로 과거 미적용 메일의 열람 기록은 표시할 수 없다. 이 배포는 픽셀·보고서 백엔드·추적 migration 006을 활성화하지 않는다.

회신 필터는 동기화된 이메일 대화에서 발송 이후 자동 응답으로 분류되지 않은 수신 메시지가 있는 발송건을 보여 준다. 대화의 모든 개별 메일을 사람이 읽었다는 확정 증거로 취급하지 않는다. 열람이나 감지 없음만으로 자동 후속 발송을 실행하지 않는다.
