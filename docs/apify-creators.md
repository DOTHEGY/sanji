# Apify 크리에이터 시험 수집

`APIFY_TOKEN`은 Supabase Edge Functions Secrets에만 저장한다. 프런트엔드·브라우저·로그에 토큰을 반환하지 않는다. Instagram 로그인, PC 실행기, Render 브라우저는 사용하지 않는다.

`sanji_apify_creator_trials`에 별도로 승인한 1회성 시험을 등록하면 기존 creator-discovery cron이 상태를 확인한다. 자동 검색의 `enabled` 값을 켜지 않으며, 시험이 종료된 뒤 새 유료 실행을 만들지 않는다. 새 시험이나 예산 증액은 별도 승인 대상이다.

- 시험 전체 상한 US$0.35, 목표 30명. 한 실행 상한은 남은 예산과 US$0.11 중 작은 값.
- 실행 전 상한을 DB에 예약한다. 이전 실행의 실제 비용이 확인돼야 남은 예산을 재사용한다.
- 실행 요청 결과가 불분명하면 재시도하지 않는다. 실패·비용 미확인도 추가 유료 실행을 중단한다.
- 검색어는 시험에 저장된 목록만 사용한다. 공급자 charge cap과 결과 수 제한을 함께 설정한다.
- 결과 수·고유 계정 수·선별 수는 다르다. `no_items` 같은 공급자 결과도 과금될 수 있다.

공개 자기소개·표시 이름의 한국인 자기소개 또는 명시적인 Korean-mom 자기표현을 근거로 선별한다. 한국어 사용·일반적인 사람 이름·외모·거주 국가만으로 한국인이라고 판정하지 않는다. 법적 국적 문서를 검증하는 기능은 없으며 자기소개 원문과 프로필 URL을 남긴다. 해외 거주와 영어 콘텐츠는 제외 사유가 아니다.

이번 시험은 최근 120일 공개 활동, 푸드·웰니스·생활 주제의 콘텐츠 근거를 확인한다. 아동 중심·비공개 계정은 제외한다. 국적·언어·지역·연락 정보가 제공되지 않으면 지어내지 않는다. 팔로워 수는 관측값으로 표시하고 적은 팔로워·콘텐츠 표본에는 불확실성을 남긴다. 공개 프로필에 실제 게시된 이메일만 추출한다.

계정 중복·수신 거부를 확인한 뒤 `sanji_creator_prospects`에 미발송 상태로 저장한다. 이메일이 있으면 기존 Gmail 제안 흐름을 우선하며, 수신자·최종 카피 승인 전에는 메일을 보내지 않는다. DM 승인·발송은 구현하지 않는다.

썸네일과 게시물 요약은 수집 데이터로 표시하며 실제 프로필 화면 캡처라고 부르지 않는다. 이미지 주소는 만료될 수 있고, 팔로워·반응은 수집 시점 공개 수치다.
