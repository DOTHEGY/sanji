# 동작 범위와 운영 전 검토

## 실제 동작하는 데모 기능

대시보드, 브랜드·크리에이터 가상 카탈로그 검색/필터/상세/후보 저장/직접 추가, 회사명 및 계정 중복 검사, 상태·메모, 상품 조건·버전 이력, 양방향 주제 기반 매칭과 불확실성 설명, 최대 3개 상품 선택, 직접 작성 템플릿·변수·수신자 미리보기, 승인 후 가상 처리, 가상 대화 원본 순서와 직접 회신, 담당자·후속일·분류, 일일 제한, 채널 공통 중복 연락 차단, 거절·수신 거부 차단, 오류 로그와 브라우저 저장.

매칭은 공개 주제 태그의 겹침을 이용한 설명 가능한 데모 규칙이며 AI 모델·판매 예측이 아닙니다. 첨부는 메타데이터만 취급하고 실제 업로드하지 않습니다. 가격·조건은 직접 변경한 것만 저장합니다. CSV 내보내기, 실시간 크롤링, 운영용 첨부 저장, 복수 수신자 일괄 발송, 실제 접수·반송 webhook, 운영 DB는 미구현입니다. 운영 통계와 가격은 가상입니다. 날짜는 초기 가상 시나리오에 고정되어 있습니다.

## 실제 서비스 연동

- 인증·테넌트 권한·DB·감사 로그·암호화·보존/삭제 정책이 먼저 필요합니다. 실제 브랜드·연락처·협상 기록은 인증된 비공개 화면에만 연결해야 합니다. 현재 데모에는 운영 화면이 없습니다.
- Gmail/Google Workspace 또는 Microsoft 365 OAuth 앱, 최소 권한, 토큰 서버 보관, 경우에 따른 검증·관리자 승인 필요. 전송·회신은 Gmail API 또는 Graph 및 수신 webhook/구독으로 스레드를 보존해야 합니다. SPF/DKIM/DMARC, 반송·실패 처리, 수신 거부·사전 동의 근거, 멱등성·제한된 재시도를 서버에서 강제해야 합니다. 현재 브라우저 제한은 운영 보안 통제가 아닙니다.
- Instagram: 지정한 프로페셔널 계정의 Meta 공식 인증과 앱 권한/심사 필요. Instagram Login 및 Facebook Login 경로에 따라 계정·페이지 연결 요구가 다릅니다. 신규 상대에게 임의로 선제 DM을 보내는 기능은 구현하지 않습니다. 사용자가 시작한 대화의 읽기·답장은 허용된 계정·권한·메시징 창 등 최신 조건을 확인한 뒤 연결해야 합니다. 개인 계정 비밀번호를 받지 않습니다. 데모는 문구 복사·수동 작업 기록만 지원합니다. 가상 프로필은 외부로 열지 않습니다.
- 공개 Instagram 전체 계정 탐색·이메일 수집은 공식 API로 무제한 제공된다고 가정할 수 없습니다. 승인된 데이터 제공자, 공개 출처의 수동 검증, 공식 링크 등록 방식 등이 필요합니다. 검색 엔진 API도 별도 계약과 정책 검토가 필요합니다.
- 회사·브랜드·제조원·유통 권한은 실제 운영 시 법인 식별자·공식 출처·날짜와 별도 관계 모델로 관리해야 합니다. 현재는 간소화된 가상 관계 모델입니다. 이메일 소유 회사 검증은 수동 가상 표식이며 실제 자동 검증기가 아닙니다.
- AI 답장 생성은 미연동입니다. 향후 선택 기능으로만 추가하고 사용자 승인 없이 발송하지 않아야 합니다.

## 예상 비용 (견적 아님)

현재 데모는 별도 유료 API가 없습니다. GitHub Pages 사용 가능 여부·무료 범위는 저장소 공개 여부와 GitHub 요금제에 따라 확인해야 합니다. 무료 범위를 넘거나 비공개 호스팅이 필요하면 별도 승인 필요.

초기 운영 계획 범위: 호스팅/DB 합계 월 약 0~10만 원, 도메인 연 약 1~4만 원, 업무용 메일 계정당 월 약 1~3만 원. 전송 공급자·검색 API·AI는 사용량별 추가 비용이며 제품 선택 전에는 확정할 수 없습니다. Meta API 자체 사용료와 별개로 서버·심사 대응·유지보수 비용이 발생할 수 있습니다. 최신 제공자 요금은 아직 확인하지 않았으며 결제·권한 연결·실제 발송을 진행하지 않았습니다.
