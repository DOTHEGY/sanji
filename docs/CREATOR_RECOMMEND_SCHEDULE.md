# 추천 후 이메일 예약 (검토용)

사용자가 이 기기의 계정별 설정에서 명시적으로 켜고 메일 유형을 선택한 경우, 오늘 추천 버튼으로 새로 확정된 대상 중 검토가 끝난 이메일을 다음 달력날 오전 9시(한국시간)에 예약합니다. 기본은 꺼짐입니다. 금요일도 토요일 오전 9시로 계산합니다. 설정은 해당 브라우저의 계정별 로컬 저장소에만 보관되며 무인 추천이나 DM은 실행하지 않습니다.

저장된 검토 본문·상품을 사용하고, 기존 서버의 발신자 서명·고지와 상품·수신거부·중복 및 발송 전 검증을 적용합니다. 메일 유형이 설정되지 않았거나 검토 내용·공개 이메일·상품이 없거나 불일치하는 대상은 제외합니다. 기존 추천은 다시 예약하지 않으며 동시 추천 때문에 신규 목록과 서버가 보고한 추가 수가 일치하지 않으면 전체 예약을 중단합니다. 기록 조회가 실패하거나 형식이 다르면 예약하지 않습니다. 준비된 대상은 30명씩 나누어 처리하며 인위적인 일괄 인원 상한은 두지 않습니다.

추천 확정 및 각 예약은 별도 요청이며 일괄 원자적이지 않습니다. 예약 응답이 불명확하면 재시도하지 않고 남은 대상을 중단합니다. 계정·목록·페이지가 바뀌거나 저장된 예약 설정이 꺼지거나 메일 유형이 바뀌면 후속 요청을 중단합니다. 이미 접수된 예약은 자동 취소하지 않습니다. 검토 자료 GET은 페이지네이션이나 개별 ID 조회를 제공하지 않으므로 응답에 없는 자료는 준비 여부 미확인입니다. 이미 접수된 요청의 결과는 서버 기록에서 확인해야 합니다. 새 초안을 자동으로 생성하거나 무인 일정을 만들지 않습니다. 운영 활성화 전에는 사용자 계정의 메일 유형 설정과 기존 예약 이력을 확인해야 합니다.
