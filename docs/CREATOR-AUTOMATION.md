# 크리에이터 발굴 및 내부 PC 실행기

크리에이터 검색은 공개 검색 색인에서 계정 아이디로 중복을 제거한 후보를 저장한다. 원본 프로필·팔로워·활동 확인과 별개이다. 운영 목표는 2026-10-23부터 하루 50명으로 낮췄으며 이미 저장한 174명(당일135/전일39)은 보존했다. 유료 검색 API는 추가하지 않았다.

사용자가 제공한 dudeoji-web의 Playwright 로그인·프로필·DM 흐름을 참고해 별도 PC 실행기를 구현했다. 공식 Instagram API와 다른 내부용 브라우저 방식이다. 공식 API 인증이 성공했다고 표시하지 않는다. 공개 프로필에 이메일이 게시되어 있으면 이메일 제안을 우선 준비하고 DM 승인·최종 실행을 차단한다. 실제 발송은 기존 Gmail 최종 승인 경로를 사용한다. 비밀번호는 서버에 보내지 않는다. 운영자가 요청한 DB 세션 백업 활성화 시 Instagram 저장 상태만 서버 키로 암호화해 7일간 보관한다. 비활성화 시 DB 세션을 삭제하고 PC 연결 키를 폐기한다. `local-worker/README.md`의 절차로 사용자 PC에서 로그인한다.

기본 실행은 공개 프로필 미리보기만 확인한다. 실행당 최대 5개, 30초 간격, 서버측 하루 최대 50개이며 오류·제한 화면에서는 종료한다. 실제 표시된 수치의 문자열·출처·확인일과 프로필 상단만 저장한다. 비공개 계정은 수집하지 않는다. 미확인 값은 추정하지 않는다. 스크린샷 저장소는 비공개이며 관리자 인증 후 60초 서명 주소로만 조회한다.

DM은 웹에서 1~20개의 최종 수신자·카피를 확인해 승인할 수 있다. 이 자체로는 PC 발송 모드를 켜지 않는다. PC의 `npm run send`에서 SEND 및 실제 수신자 아이디 확인을 거쳐 매 실행 1건만 처리하고 종료한다. 전송 직전 계정·수신자·변경 여부·수신거부를 재검증한다. 계정 순환·자동 팔로우·제한 회피는 없다. 정책상 허용이나 계정 정지 방지를 보장하지 않는다.

발신 표시 확인은 전달·열람 확인이 아니다. 클릭 전 오류는 중단, 클릭 후 모호한 결과는 unknown으로 보존하며 자동 재시도하지 않는다. sending 응답이 30분 이상 없으면 unknown으로 분리한다. PC 로컬 저널도 중단된 전송을 복구하되 다시 보내지 않는다. 원본의 버튼 클릭만으로 성공 처리하는 판정은 채택하지 않았다.

PC 연결 키는 무작위32바이트, 서버에는 SHA-256 해시만 보관, 7일 만료, 재발급·해제로 폐기한다. 제한된 워커 엔드포인트는 자기 소유의 승인 작업/프로필에만 접근한다. 관리자 화면 접근 권한을 제공하지 않는다. 로컬 브라우저 프로필은 사용자 PC ~/.sanji-instagram/에 남고, 활성화된 DB 백업은 서비스 전용 테이블에 암호화한다. 설정 변경 시 기존 키를 폐기하여 이전에 발급한 낮은 권한의 키로 세션을 조회할 수 없게 한다.

필요: Node.js22 이상, 실행기 npm 의존성 및 Chromium 설치, PC 켜짐. 추가 호스팅 결제 없음. 기존 Supabase DB·저장소·네트워크 사용량은 요금제에 따른다. 대상 사용자 PC의 Instagram 로그인과 실제 DM 발송은 별도 시험 승인 전까지 미실행이다.

운영 적용: 202610230003_creator_local_worker.sql, bright-function, Pages, 공개 코드 전용 다운로드 ZIP. DB 변경은 profile_preview 열·비공개 이미지 버킷·서비스 전용 원자적 claim 함수만 추가하며 기존 DM 작업을 자동 승인하거나 발송하지 않는다. 복구: PC 연결 키 해제 후 UI/Edge 이전 배포 복원. 기존 발송·검색 자료는 삭제하지 않는다.
