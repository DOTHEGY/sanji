# 크리에이터 자동 발굴

업로드된 dudeoji-web 소스를 검토했다. 해당 앱의 검색은 Prisma에 이미 수입된 CSV/RTF 계정을 필터링하는 기능이다. `worker/instagram/login.ts`는 직접 로그인한 Playwright 세션을 저장하고, `worker/instagram/driver.ts`는 웹 UI로 DM을 전송한다. 이것은 Instagram 공식 메시지 API가 아니다. 자동 팔로우, 계정 순환, 브라우저 세션의 서버 업로드는 이식하지 않았다.

산지에는 별도의 공개 웹 검색 수집기를 추가했다. 네이버·Google·Bing·DuckDuckGo 검색에서 Instagram 프로필 후보를 추출하고 아이디로 중복 제거한다. 검색 색인의 내용과 실제 Instagram 최신 콘텐츠 검증을 구분한다. 주제 검색에 프로필이 노출되었으나 본문이 없는 경우에는 적합성 미확인 후보로 표시하며 콘텐츠 주제를 확인했다고 주장하지 않는다. 팔로워·반응·활동 수치를 만들지 않으며 개인 건강 상태는 평가하지 않는다. 검색은 5분 간격, 일일 목표 최대 500명이다. 목표 달성이나 검색 제공자 접근은 보장되지 않는다. 검색 출처·시각·오류·오늘/어제 수를 인증된 화면에 표시한다. 검색용 유료 API/AI 요청은 없다. Supabase 함수·DB·네트워크 사용료는 기존 요금제에 따른다.

크리에이터 발굴 화면에 직접 DM 카피를 저장할 수 있다. `{{아이디}}`만 치환하고 본문을 다시 쓰지 않는다. 미발송 후보에 저장된 카피를 갱신한다. 신규 상대 선제 DM 자동 발송은 활성화하지 않았으며 서버에서도 활성화 요청을 거절한다. 기존 공식 연동에서 허용되는 수신 대화 회신 기능과 분리했다. 실제 DM 발송 시험은 하지 않았다.

중지: 크리에이터 발굴 → 자동 검색 중지. 예약기 작업명 `sanji-creator-discovery`. 검색 설정·후보는 RLS 및 관리자 회원 인증 뒤에서만 조회한다. 브랜드 발굴 목표 40명/자정 예약, 기존 이메일 발송, 추적 활성화 설정은 변경하지 않는다.
