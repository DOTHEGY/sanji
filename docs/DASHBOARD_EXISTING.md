# 기존 자료로 보는 운영 기록

이 화면은 기존 `/state` 응답과 사용자가 브랜드 화면에서 이미 조회한 `/discovery` 응답을 재사용합니다. 대시보드를 여는 것만으로 새로운 요청이나 수집을 시작하지 않습니다. 브랜드 발굴 기록은 같은 로그인 세션에서 마지막으로 브랜드 화면을 연 뒤에만 사용할 수 있으며 조회 시각을 표시합니다. 늦은 응답은 다른 화면이나 다른 로그인 세션을 덮어쓰지 않습니다.

- 오늘의 신규 후보·이메일 확보 후보·이메일 주소는 기존 `sanji_discovery_history`의 한국시간 기록입니다. 업체 고유 수가 아니라 후보 기록 수이며, 이메일 주소 수는 중복을 제거합니다. 미조회나 날짜가 없는 경우 확인 불가입니다.
- 후보·주소, 접수 및 예약·실패는 이미 불러온 범위에서 브랜드/제조사/공식 유통사로 확인된 대상만 집계합니다. 각각 전체 회사·전체 발송 수가 아닙니다. `/state`의 outbox 최대 500건과 예약 최대 200건 제한을 그대로 둡니다.
- 오늘·어제 접수 관찰은 이메일 접수 outbox ID와 같은 대상 대화의 발신 메시지 ID가 일치하고 메시지 시각이 있는 건만 한국시간 날짜에 배정합니다. 일부일 수 있으며 도착 성공이 아닙니다. 반송은 같은 브랜드의 영구 DSN에 명시된 주소 단위 관찰로, 개별 발송건 귀속을 주장하지 않습니다.
- dot 확인 횟수·고유 인원·신규·중복·실패·잔여와 크리에이터 전체 DB 수는 기존 응답에 없어 확인 불가로 남깁니다. 누락 날짜를 0으로 보충하거나, 과거 기록을 현재 수집 상태로 표시하지 않습니다.

`docs/previews/dashboard-existing-desktop.png`와 `dashboard-existing-mobile.png`는 모의 데이터 화면입니다. 서버·DB 스키마·인증·수집·발송 설정은 변경하지 않습니다.
