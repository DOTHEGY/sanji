# 협업 브리프 근거 검토 개선안

로컬 검토와 빌드를 마친 개선안으로, 사용자 승인에 따라 PR을 게시하고 정식 CI에서 검증합니다. 운영 반영은 CI 통과 및 최종 검토 후 진행합니다. 새 자격증명·유료 서비스·외부 발송은 이 변경의 범위가 아닙니다. 현재 운영 버전의 키워드 검색에 뉴스·업체 채널이 섞인 한계를 줄이기 위한 검토 보조 기능입니다.

## 검색 전에 확인할 내용

- 협업 목적에서 공개 콘텐츠 주제를 찾아 편집 가능한 검색어를 제안합니다. 고정된 소규모 주제 사전과 명시적 단어를 사용하며 일반 자연어 이해 모델이 아닙니다.
- ‘편의점에 호빵을 런칭할 크리에이터’는 ‘편의점 호빵’으로 정리합니다.
- ‘급식 업체의 IP가 되어줄 먹방 클린 크리에이터’는 ‘급식 먹방’과 ‘먹방 음식 리뷰’를 제안합니다. 두 번째 검색이 확장이라는 사실과 최대 검색 2회 소비를 표시합니다.
- 클린 이미지·논란 없음, 시청자 연령, 브랜드 적합성, 협업 의사, IP 권리 및 조건은 확인된 사실로 채우지 않고 별도 검토 항목으로 남깁니다.
- 단순한 ‘뉴스 제외’는 긍정 검색어로 쓰지 않습니다. 부정·인용 등 모호한 제외 조건은 사용자가 검색어를 직접 지정하기 전 API 요청하지 않습니다.
- 자동 제안한 검색어는 목적 변경 시 비우고, 사용자가 직접 수정한 검색어는 명시적인 수동 입력 안내와 함께 유지합니다.

## 결과 검토

YouTube의 반환 순서를 유지합니다. 점수, 평판, ‘검증된 크리에이터’, 성공 가능성 등의 값은 만들지 않습니다.

각 채널에는 다음을 표시합니다.

1. 실제 제출한 협업 목적 및 후보가 나온 검색어. 검색어 자체는 원문 근거가 아닙니다.
2. 요청 주제 표현이 나타난 채널 제목·설명, 영상 제목·검색 설명 일부의 발췌와 원문 링크.
3. 직접 등장한 표현, 사전에 표시한 별칭/번역 표현, 관련어를 구분합니다. 예를 들어 호빵과 찐빵은 동일하다고 단정하지 않고 관련어로 표시합니다.
4. 부정·인용 문맥이 있으면 그 의미를 직접 확인하라는 경고를 붙입니다. ‘비건이 아닌’도 단순 키워드 일치만으로 비건 적합 판정을 하지 않습니다.
5. 표시된 원문에서 확인하지 못한 주제. 확인하지 못했다는 것은 부적합 판정이 아닙니다. 검색 설명이 일부이며 전체 채널·영상 시청 검증은 하지 않습니다.

## 뉴스·업체 접기

두 필터 모두 기본 해제이며 사용자가 선택할 때만 동작합니다. 뉴스 전문 채널·렌탈 전문 업체 등 설명의 명시적 표현에만 근거를 붙입니다. 상호명, 광고 문의, 개인 굿즈 스토어 링크, 뉴스 주제 영상 하나만으로 분류하지 않습니다. 질문·인용·부정·과거 소속 등 모호한 설명은 분류하지 않습니다.

필터는 삭제가 아닌 접기입니다. 접힌 후보의 개수·근거를 보며 다시 펼칠 수 있고, 원래 순서 및 입력한 연락처·초안을 유지합니다. 필터 변경은 API를 호출하지 않습니다. 업체가 유용한 요리 콘텐츠를 만드는 경우 콘텐츠 근거와 업체 표현을 독립적으로 보여 줍니다. 운영 주체·소속 확인으로 오해하면 안 됩니다.

## 공개 업무 이메일 편의

- 명시적인 버튼으로 해당 채널의 About 원문을 열고, 사용자가 그 URL을 연락처 확인 출처에 넣을 수 있습니다.
- 주소를 자동 추출하거나 수신 동의로 간주하지 않습니다. 게시 용도·원문·수신자를 확인하는 기존 절차를 유지합니다.
- 초안은 실제 공개 영상 제목을 언급할 수 있지만 시청 완료·적합성 검증·협업 조건 확정 등을 주장하지 않습니다.
- 결과에 연결된 원래 협업 목적을 초안에 사용합니다. 검색 후 입력란을 바꾸더라도 이전 결과를 새 조건으로 평가한 것처럼 표시하지 않습니다.
- 공식 사이트 자동 수집의 실제 허용 출처는 여전히 0개입니다. 개인정보 담당·불명확한 소속 등의 주소를 자동 수집하지 않습니다.

## 검증과 한계

`npm run test:youtube-relevance`로 검색·근거·제외·소속 표현·개인정보 및 요청 차단의 순수 테스트를 실행합니다. 기존 이메일 서비스·SQL 회귀 테스트를 별도로 실행합니다. `npm run build:supabase`로 전체 빌드를 확인합니다.

신규 mocked Chromium 테스트는 작성하되 현재 로컬 환경의 브라우저 실행 제한 때문에 실행 완료라고 주장하지 않습니다. 운영 전 사용자 승인 아래 정식 CI에서 전체 브라우저 테스트 및 시각 검토가 필요합니다. 의미 있는 실채널의 적합성, 최신 논란, 실제 협업 의사, 이메일 전달·수신은 이 테스트가 검증하지 않습니다.
