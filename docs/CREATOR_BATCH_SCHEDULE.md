# 추천 이메일 일괄 예약 검토

오늘 확정된 추천 목록에서 `이메일 일괄 예약 검토`를 누르면 저장된 공개 이메일·검토 완료 초안·상품 1~3개가 모두 있는 대상을 선택할 수 있습니다. 없거나 중복·이력 확인이 필요한 대상은 이유를 표시하며 내용을 자동 생성하지 않습니다. 오늘 추천만 대상이고 최대 30명씩 처리합니다. 추천 확정만으로 예약하거나 자동 발송하지 않으며, 반복 자동화 설정도 만들지 않습니다.

메일 유형을 명시하고 미리보기하면 기존 `/creator-proposal/target`과 `/drafts`를 사용합니다. 이 과정에서 후보 또는 임시 초안이 저장될 수 있으나 예약·발송은 하지 않습니다. 사용자는 각 최종 수신자·제목·본문과 추적 안내를 확인하고 개별 체크한 다음 한국시간 공통 예약 시각을 입력합니다. 검토 버전을 다시 대조한 후 기존 `/schedule`에 요청하므로 서버의 공개 출처·수신거부·중복·기존 이력·상품·발송 직전 검사를 유지합니다. 광고성 여부를 임의로 기본값 지정하지 않습니다.

한 요청의 응답이 실패하거나 예약 시간이 불일치하면 결과 확인 필요로 표시하고 나머지를 중단합니다. 자동 재시도하지 않습니다. 화면의 기존 예약 목록은 최대 200건이므로 전체 중복 여부는 서버를 신뢰해야 합니다. 페이지·날짜·세션 변경 시 남은 작업을 중단하고, 이미 전송 중이던 요청의 결과는 정식 예약 목록에서 확인해야 합니다.

이 화면은 서버·마이그레이션·권한·설정 변경이 없는 수동 일괄 검토 흐름입니다. 미준비 초안을 생성하거나 추천 버튼 하나로 반복 자동 예약을 활성화하지 않습니다. 미래 반복 예약의 시간·문안 설정과 내구성 있는 서버 실행기는 별도 구현과 검토가 필요합니다. 실제 발송·예약을 테스트하지 않았습니다.
