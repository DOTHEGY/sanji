# 복구 크리에이터 추천 · 검토용 배포 계획

## 데이터와 범위

- 사용자 제공 복구 CSV 13,932행을 원본의 source_id·출처·소개란과 함께 별도 `sanji_creator_recovery`에 저장합니다. 기존 크리에이터 목록·브랜드 후보·발송 내역은 수정하지 않습니다. 알려진 테스트 계정 6행은 애초에 가져오지 않습니다.
- Instagram 링크가 없는 282행은 링크 확인 대기로 보존합니다. `link_status`와 `entity_type`은 별도로 보관하며, 계정명을 가지고 링크나 소유관계를 추정하지 않습니다.
- 소개란 이메일 2,887계정 및 공유 이메일 관계를 보존합니다. 주소는 수신 가능 여부·소유권·발송 허락이 미검증입니다. 팔로워 0과 누락을 구분하며 숫자와 소개란은 현재값으로 가장하지 않습니다.
- 주제와 역할이 같은 한 키워드에만 의존하지 않도록, 한국어 소개에 더해 카테고리·소개란의 주제 또는 소개란의 주제·창작자 역할이 별도로 나타난 계정만 우선 후보로 두었습니다. 1,146건은 기초 규칙의 잠정 후보이며 한국 국적·현재 활동·계정 유형을 확정한 숫자가 아닙니다. 다른 12,786건은 검토 대기입니다.
- 기존 계정 이력, 신규 데이터 고유 handle/source_id 및 추천 테이블을 함께 확인합니다. 과거 데이터에 남지 않은 이력은 중복 판정에 사용할 수 없습니다. 관측된 기존 크리에이터 후보 5건과 복구 잠정 후보 사이에는 중복이 없었습니다.

## 현재 구현

- 소유자별 전용 테이블과 중복 없는 가져오기, SQL 트랜잭션과 중단 후 재실행을 지원하는 Management API 스크립트. 스크립트는 `--apply`가 없으면 dry-run만 합니다. 배치 단위 커밋이므로 중간 실패 시 같은 명령을 재실행합니다. 기존 행·사용자 상태는 덮어쓰지 않습니다.
- 기존 크리에이터 찾기 화면의 오늘·날짜별 추천, 기록하지 않는 미리보기, 목록 확정, 목표·실행 시간 설정, 보류·제외·연락 완료 및 관리, 아이디 복사·CSV·이메일 필터. 기본 자동 실행은 꺼짐입니다.
- 일 1회 / Asia/Seoul 설정에 따라 이미 등록된 5분 주기 창에서 추천합니다. 조회 제한·재시도·비용 상한은 설정 가능하지만 외부 조회 엔진과는 미연결이며 실제 유료 호출은 없습니다.
- Instagram Business Discovery 어댑터는 공식 토큰·프로페셔널 연결계정과 이미 아는 상대 아이디가 주어진 경우를 위한 호출 코드와 실패 처리만 준비했습니다. 앱 OAuth·실서비스 연결 경로에는 아직 연결되지 않았고, 실제 인증·API 호출도 하지 않았습니다. 설명란 이메일을 자동 갱신한다고 주장하지 않습니다.
- 태그바이 승인 페이지 리더 인터페이스, 20행 제한, 로그인 만료·레이트 제한 중단, 검증된 페이지와 커서의 원자적 저장·재개를 모의 시험했습니다. 태그바이 API·자동 로그인·내보내기 여부·이용약관상 허용 범위는 미확인이고, 실제 브라우저 연결 구현과 유료 계정 시험은 남았습니다. 비밀번호·쿠키·토큰을 저장하거나 유료 호출을 실행하지 않습니다.
- 링크 없는 항목에 대한 실제 검색·동일 계정 확인은 아직 실행하거나 연결하지 않았습니다. 실패하면 미확인으로 유지합니다. 프로필 실패 시 기존 bio·메일·숫자를 지우지 않는 병합 처리는 모의 시험했습니다.

## 운영 반영을 승인받으면 수행할 작업

1. 현재 DB·함수 상태 확인 및 백업, 새 마이그레이션 적용. 새 테이블·함수만 추가합니다.
2. 13,932행을 100행씩 전용 테이블에 적재하고 행 수·공유 이메일·링크 누락·중복을 확인합니다. 두 번째 실행은 기존 행을 유지합니다.
3. Edge Function 및 GitHub Pages UI를 배포하고 관리자 인증·화면을 검증합니다. 자동 실행은 꺼진 상태로 둡니다. 기존 자동 메일 발송 설정·예약은 변경하지 않습니다.
4. 매일 자동 추천 활성화, 실제 Meta/Tagby 인증, 신규 과금 또는 유료 수집은 각각 별도 승인과 필요한 계정 권한 확인 후 진행합니다.

복구: 배포 전 Edge 함수·UI 버전으로 되돌릴 수 있습니다. 전용 테이블은 데이터를 백업한 후 별도 삭제 승인 없이는 보존합니다. 자동 추천을 켠 경우 설정에서 끄면 더 이상 신규 추천을 생성하지 않습니다.

## 태그바이 비용 판단

사용자가 말한 월 7만원 플랜을 기준으로, 과거 DB의 잠정 후보 1,146건은 30명/일 단순 산술로 최대 약 38일 분량이나, 최신성·한국 국적·활동·공구 적합성이 미검증이므로 실제 사용 기간은 짧아질 수 있습니다. 회사·팬 계정도 분류가 완벽하지 않습니다. 공식 Meta Business Discovery는 이미 아는 프로페셔널 계정의 일부 공개 지표 갱신에 적합하고 무제한 개인 계정·소개란·신규 발굴을 대체하지 않습니다.
태그바이 40건 열람은 대화상 사용자 관찰이며 이 환경에서는 재확인하지 않았습니다. 공식 내보내기, 자동 조회 허용 범위, 중복 제외 신규 적합 후보, 유료 플랜 기능과 해지 후 접근 여부가 검증되지 않아 계속 결제해야 한다고 확정할 수 없습니다. 승인 후 소량 대조에서 복구 DB 대비 신규 적합 후보/월과 실제 시간·조회비용을 비교한 뒤 7만원 이상의 가치가 있는지 판단합니다. 구독 변경은 하지 않습니다.
